1기준안 (예산안과 같은 기준단가)

식대·숙소·여비·통신·집기·청소·무인경비 등 모든 단가는 판관비 예산안 자동작성 양식의 「기준단가」를 그대로 씁니다. 새 기준안을 반영하려면 예산안 화면에서 '새 기준안 반영'을 한 뒤(웹판은 다시 올린 뒤) 여기서 연도를 고르세요.

2현장 입력 꼭 필요한 칸만 보입니다 — 인원·대수 등은 '세부 조정'에 기준안 기본값으로 접혀 있음 · 체크 = 반영 항목

저장한 현장 예시:
현장 구분 이 기간에 해당하는 것을 모두 고르세요 — 고른 것에 맞는 칸만 보입니다. 견본주택은 오픈 분기면 「오픈」, 이미 오픈한 뒤면 「운영」(오픈 일정을 묻지 않음) 중 하나
먼저 위에서 현장 구분(견본주택 오픈 / 견본주택 운영 / 입주 / 분양사무실)을 고르세요.
월별 단계·행사 달마다 행사를 고르면 식대·확정일자·안내문 등기가 반영되고 머리글에 표시됩니다
단계는 일정(오픈·사전점검·입주·분양사무실)에서 자동으로 잡히고, 머리글은 비우면 자동 글 — 인원은 비우면 기준안 값(연한 글씨).
결재란
칸 너비 (엑셀 글자 수, 비우면 비고 너비에 맞춤) · 서명칸 높이 (포인트)
역할을 비우면 첫째 담당 · 마지막 승인 · 가운데 검토. 같은 역할이 이어지면 머리글을 합칩니다. 이름은 적으면 직위 옆에 인쇄됩니다.
직접 추가 줄 기준안에 없는 비용(CCTV 설치, 방역, 네트워크 공사 등)
금액 칸에 '=1500000*2' 처럼 산식을 적으면 엑셀에도 산식으로 들어갑니다.

3계산 결과

비우면 자동(M/H 오픈비용 · M/H 운영비용 · 입주비용 · 운영비용) 기간 합계 원
금액 칸을 누르면 직접 고칠 수 있고(산식 '=…'도 됨), 비고도 누르면 고칠 수 있습니다 · 고친 칸은 노란색, ↺ 로 자동값 복귀 · 마우스를 올리면 산식
