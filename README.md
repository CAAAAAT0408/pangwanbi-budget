# 판관비 예산안 자동작성

PM팀 현장별 「사업비(판관비) 예산편성」 엑셀을 현장 조건만 넣으면 기준안대로 자동 산출해 **회사 양식 그대로** 만들어 주는 도구입니다.
설계사무소 설계개요(PDF·엑셀)에서 세대 구성을 읽고, 매년 새 「PM팀 판관비 예산기준(안)」을 넣으면 단가가 바뀝니다.

- **웹판(설치 없이)**: https://caaaaat0408.github.io/pangwanbi-budget/ — 브라우저 안에서 계산·엑셀 작성(파일은 밖으로 안 나감)
- 결과물(NN년 예산 시트)의 월별 금액 칸에는 값 대신 **산식(계산 수식)** 이 들어가 칸을 누르면 계산 과정이 보입니다(예: `=(90+45+54+21)*2000*1000`). 화면에서도 금액에 마우스를 올리면 보입니다. 식대·유류비/숙박비·통신요금·전기료처럼 구간이 나뉘는 세목은 한 줄로 합치고 산출근거에 구간별 단가 × 개월을 줄바꿈으로 적습니다.
- **지출계획서 자동작성**(3개월 선급금 지출계획, 같은 기준단가): 웹판 https://caaaaat0408.github.io/pangwanbi-budget/jichul/ · PC 판 `지출계획서 열기.bat` — 현장 구분(견본주택 오픈 / 견본주택 운영 / 입주 / 분양사무실)·일정·행사(중도금대출·옵션 등)·결재자를 넣으면 「M/H 오픈비용·운영비용·입주비용 지출계획서」 양식 엑셀(산식·결재란 포함)
- 사용법·규칙·구조: [사용법.md](사용법.md)
- PC 판 실행: `페이지 열기.bat` (이 PC 의 Excel 로 계산, 포트 8792) — 새 기준안·회사 양식 반영, PC 폴더 저장, 그림 미리보기는 PC 판에서
- 웹판 올리기(관리자용): 엔진(`tool\`)·양식을 고친 뒤 `python tool\sync_web.py` → `깃허브 올리기.bat` (커밋·push, 처음엔 GitHub 로그인 창이 열림)
- 필요한 것: Windows 10/11 + Excel + Python 3.13 (`openpyxl`, `pywin32`, `pymupdf`, `xlrd`), 그림 PDF 설계개요는 Windows 한국어 글자 인식(OCR) 언어 팩

폴더: `app\`(화면 서버·화면) · `tool\`(양식 생성·기준안 해석·설계개요 읽기·회사 양식 작성·지출계획서 엔진 jichul.py) · `회사양식\`(경영기획팀 양식) · `예시\`
